## 1. 编程思想与习惯（常识）

### 1.1 做题流程
1. **先特殊情况，再一般**（L1）——先处理边界/特例，再写主逻辑。
2. **做之前先检查行不行**（L59）——数据范围、会不会超时，想清楚再动手。
3. 用**伪代码**：先分析、再套编写格式（L25）。
4. 降低计算规模是核心手段：斐波那契的递归 / 迭代（调用）对比（L53）。

### 1.2 代码风格
- 变量**用的时候再定义**，缩短作用域、避免混淆（L26）。
- **效率高 == 枚举少**（L27）。
- 用 `printf()` 输出中间结果做调试（日志系统）（L40）。
- 用 **bool 标志元素**记录状态（L78）。
- **解耦**：把处理逻辑和数据分开（L132）。

### 1.3 数据与精度
- 判断输入数据正确与否（L3）。
- 自然语言表达式与电脑的写法**不相同**（L4）。
- 非 0 整数为真，0 为假：`!2 == 0`、`!3 == 0`、`!0 == 1`（L9）；`0 = false`、`1 = true`（L28）。
- 浮点数要注意 **`0` 与 `+0`** 的细节（L2）。
- 高精度小数（L10）：用 `fabs(delta) < eps` 判断收敛（L11），`const double eps = 1e-8;`（L12）。

## 2. 运算符与表达式

### 2.1 算术与赋值（L13–L20）
| 写法 | 含义 |
| --- | --- |
| `++` | 加 1 |
| `k++` | 返回 k，再加 1 |
| `++k` | 先加 1，返回 k+1 |
| `m += 2` | `m = m + 2` |
| `*=` | 乘后赋值 |
| `%` | 取余（可以替代除法求素数，L8） |

### 2.2 关系与逻辑
- 在 `a<b<c` 这种式子里（原文写作 `a《B《c`），`a<b` 输出的是 **0、1**（L5）——即只比较了前两个，结果再和 c 比。
- `&&`（与，有**短路性**）、`||`（或）、`!`（非）、`^`（异或：相同为 0，不同为 1）（L7）。
- 短路特性要主动利用：`if (p != NULL && p->x > 0)` 才不会崩（L41）。

## 3. 控制流

### 3.1 分支
- `if` / `else if` / `else`：某个分支成立 → 输出并结束；不成立 → 继续往下判断（L30）。

### 3.2 循环（L35–L39）
| 写法 | 执行顺序 |
| --- | --- |
| `for (执行前运行; 循环条件; 执行（然后进行前一步）)` | 括号内第 1、2 项在循环前/每次判断时执行 |
| `while (循环条件)` | **先判断**再执行 |
| `do { } while ()` | **先执行**再判断，至少跑一次 |

- 循环的代价：**速度慢**（L64）。

### 3.3 跳转
- `continue`：结束**本次**循环，开始下一次（L36）。
- `break`：结束**整个**循环（L37）。

## 4. 数组（L42–L48）

1. 用 `for` 循环做输入输出、比较。
2. 数组复制 `memcpy`（复制到 b，从 m 复制，长度）——即 `memcpy(b, m, len)`。
3. 防止**数组溢出**。
4. 防止**访问超界**。
5. 初始化 `int a[n] = {1};` → 只有第一个元素为 1，**其余元素自动为 0**（原文"除开 n 以外"，指除首个元素外）。
6. **常量数组**：不用规定长度，可用于简化代码（L133）。

## 5. 字符串（以 `'\0'` 结尾的 char 数组）

### 5.1 字符
- `char s[100];` 读字符时**不跳过空格、回车**（L82）。
- 字符常量用单引号 `''`，单引号本身要转义 `\'`（L84）。
- `'d' == 100`，字符本质是整数编码（L85）。
- 小写改大写：`printf("%c\n", c - 'a' + 'A')`（L86）。
- `putchar()` / `getchar()` 单字符输入输出（L87–L89）。

### 5.2 字符串要点
- 字符串 = **以元素 0（`'\0'`）结尾的字符数组**（L90, L120）。
- `0`（ASCII 的 NUL，码值 0）**不等于** `'0'`（字符 `'0'`，码值 **48**）〔订正：原文写 32，32 其实是空格〕（L91，对照 `image.png` 的 ASCII 表）。
- 需要 `#include <string.h>`（L92）。
- `%s` **遇到空白字符就停下**；`strlen()` 求长度（L94）。
- `fgets(输入到, 长度, 来源)`：读入 1 行字符，然后把读入的最终值给目标数组（L96）。
- `strrev()` 字符串反转〔订正：原文写作 `strrve`；该函数非标准 C，MSVC 才提供，通用写法是自己反转或用 C++ `reverse`〕（L98）。

### 5.3 转义字符（L99–L104）
| 写法 | 含义 |
| --- | --- |
| `'\0'` | 空字符（字符串结束标志） |
| `'\t'` | 制表符（L61） |
| `'\031'` | 八进制转义〔订正：`031` 八进制 = 25，并不是 `':'`；`':'` 的八进制是 `'\072'`〕 |
| `'\X3A'` | 十六进制转义，`0x3A = 58` |
| `':'` | 十进制 58，即 `0x3A` |

→ 原文把三条都当成 `':'`；真正等于 `':'` 的是后两条，八进制那行的数字写错了。

### 5.4 常用字符串处理函数（L106–L114）
| 函数 | 作用 |
| --- | --- |
| `strcmp` | 比较 |
| `strlen()` | 长度；括号里是数组名 a/b，**当数值为 0（不是符号 `'0'`）时结束计数** |
| `strcpy` | 复制 |
| `strcat` | 拼接 |
| `strchr` | 查找字符 |
| `sprintf` | 格式化到字符串 |
| `sscanf` | 从字符串格式化读入 |
| `atoi` / `atof` | 字符串转整数 / 浮点数 |

## 6. 输入输出

### 6.1 scanf 原理（L66–L69）
- 按格式串指定的格式**扫描**：匹配上就读入，**匹配不上就停止**；
- 自动跳过空格和制表符；
- 返回值 = **正确读入的域个数**（可用于 `if (scanf(...) != n) break;`）。

### 6.2 重定向（L71–L74）
```cpp
freopen("in.txt",  "r", stdin);   // 输入重定向
freopen("out.txt", "w", stdout);  // 输出重定向
```

### 6.3 整行读入
- 处理字符串时**不要一个一个读**，整行读入之后再处理数组（L126）。
- `fgets` 性能 >> `getchar`（L128）；EOF 相关〔订正：返回 `-1` 的是 `getchar`，`fgets` 失败返回 `NULL`〕。
- 常用写法：`for (int i = 0; s[i] != '\0'; i++)`（L127）。

---

## 7. 算法与复杂度

- **斐波那契**：递归 or 迭代调用，选规模小的写法（L53）。
- **矩阵**（L56，用于快速递推）：
  ```
  { f(n-1)  f(n) } × ( 0  1 )
                      ( 1  1 )
  ```
- **a^n**：`for` 循环（线性）→ 二分（对数）→ 对数形式复杂度，逐级变快（L58）。
- **状态机（状态转换）+ 模式匹配**（L121）：
  - 状态机：用状态表示当前处理到哪一步；
  - 模式匹配：在输入里一直寻找需要的特定字符，匹配到后再处理（L125）。
- 编译器优化：`-O2` 二级优化（L119）。
